# S'Argent(旧: Lumina Nail)

ネイルサロン向け 予約・会計管理 WEBアプリ(PWA対応・iPhoneホーム画面追加対応)

> ⚠️ アプリの表示名は「S'Argent」に変更されましたが、GitHubリポジトリ名・公開URL・
> Firebaseログイン用メールアドレス(owner@lumina-nail.local等)は、既存のログイン設定を
> 壊さないよう `lumina-nail` のまま変更していません。画面に表示される名前・アイコンのみが
> 変わります。

すべての開発ステップが完了しました(10/10)。**パソコンへのソフトのインストールや
ターミナル操作は一切不要**で、GitHubに保存するだけで自動的に公開される構成になっています。

## 全体の流れ

1. GitHubにこのフォルダの中身をアップロードする
2. Firebase(データ保存サービス)を無料で準備する(すべて画面のクリック・コピペのみ)
3. GitHubの設定を1箇所ONにする
4. 数分待つと、自動的にアプリが公開される

---

## 1. GitHubにアップロードする

1. [GitHub](https://github.com/) にログイン(アカウントがなければ無料で作成)
2. 右上の「+」→「New repository」をクリック
3. Repository name(リポジトリ名)に **`lumina-nail`** と入力(この名前にしてください。
   別の名前にしたい場合は `vite.config.ts` 内の `REPO_BASE_PATH` も同じ名前に書き換える
   必要があります)
4. 「Public」を選択 → 「Create repository」
5. 作成された画面で「uploading an existing file」というリンクをクリック
6. この`lumina-nail`フォルダの中身(フォルダ自体ではなく、**中に入っているファイル・
   フォルダすべて**)を、その画面にドラッグ&ドロップする
7. 画面下の「Commit changes」をクリック

> 💡 フォルダの中身をまとめてドラッグ&ドロップすればアップロードできます。1つずつ
> 選ぶ必要はありません。

## 2. Firebase(データ保存サービス)を準備する

### 2-1. プロジェクトを作る

1. [Firebase Console](https://console.firebase.google.com/) を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 名前を入力(例:lumina-nail)→ 「続行」
3. Googleアナリティクスは「オフ」のままでOK → 「プロジェクトを作成」

### 2-2. ログイン機能をONにする

1. 左メニュー「Authentication」→「始める」
2. 「メール/パスワード」を選び、スイッチを「オン」→「保存」
3. 「Users」タブ→「ユーザーを追加」で、以下の2人を登録する

| 画面上のID | メールアドレス欄に入力する値 | パスワード | 権限 |
| --- | --- | --- | --- |
| `owner` | `owner@lumina-nail.local` | `password123` | オーナー |
| `guest` | `guest@lumina-nail.local` | `987654321` | 従業員 |

> ログイン画面では `owner` / `guest` とだけ入力すればよく、`@lumina-nail.local` の
> 部分を入力する必要はありません。

### 2-3. データベース(Firestore)を作る

1. 左メニュー「Firestore Database」→「データベースの作成」
2. 「本番環境モード」を選ぶ → 「次へ」
3. ロケーションは「asia-northeast1(東京)」を選ぶ → 「有効にする」
4. 作成後、上部タブの「ルール」を開き、中身をすべて選択して削除
5. このフォルダに含まれる `firestore.rules` というファイルをテキストエディタ
   (メモ帳など)で開き、中身をすべてコピーして、Firebase Consoleの「ルール」欄に貼り付ける
6. 「公開」ボタンをクリック

### 2-4. アプリの設定値を取得してGitHubに貼り付ける

1. 左上の歯車マーク →「プロジェクトの設定」
2. 下の方の「マイアプリ」→「</>」(ウェブ)のアイコンをクリック
3. ニックネームを入力(例:lumina-nail)→「アプリを登録」
4. 表示される`firebaseConfig`の値(apiKey、authDomain、projectIdなど)をメモしておく
5. GitHubの自分のリポジトリ画面に戻り、`src/lib/firebaseConfig.ts` というファイルを開く
6. 右上の鉛筆マーク(Edit this file)をクリック
7. ファイルの中の「ここにFirebaseの◯◯を貼り付ける」と書かれた部分を、4でメモした
   実際の値に1つずつ書き換える(引用符 `'　'` はそのまま残す)
8. 画面下の「Commit changes」をクリックして保存する

> 💡 これらの値は非公開にする必要のない値です(実際のセキュリティは
> Firestoreのルールで守られています)。そのままGitHubに保存して問題ありません。

## 3. GitHub Pagesを有効にする(公開設定・最初の1回だけ)

1. GitHubの自分のリポジトリ画面で「Settings」タブを開く
2. 左メニューの「Pages」をクリック
3. 「Source(ソース)」を **「GitHub Actions」** に変更する

これだけで完了です。手順2-4で「Commit changes」した時点で、自動的にビルド・公開が
始まります。

## 4. 公開されたか確認する

1. リポジトリ画面上部の「Actions」タブを開く
2. 一番上に表示されている実行(黄色い丸、進行中)をクリックして進み具合を見る
3. 緑色のチェックマークになれば公開完了(2〜3分ほどかかります)
4. 公開されたURLは次の形式です(`ユーザー名`は自分のGitHubのユーザー名に置き換え)

```
https://ユーザー名.github.io/lumina-nail/
```

> このURLは、Settings → Pages の画面上部にも表示されます。

## 今後、内容を変更したいとき

`src/`フォルダ内のファイルをGitHub上で編集して「Commit changes」するだけで、
自動的に再ビルド・再公開されます(Actionsタブで進み具合を確認できます)。

## iPhoneホーム画面への追加方法

1. SafariでアプリのURL(上記の`https://ユーザー名.github.io/lumina-nail/`)を開く
2. 画面下部の共有ボタン(四角から矢印が上に伸びるアイコン)をタップ
3. 「ホーム画面に追加」を選択
4. 追加すると、ブラウザのアドレスバーなどが表示されないアプリのような見た目で起動する

オフライン時(電波が入らない場所など)は、直前まで表示していたデータの**閲覧のみ**
可能です。画面上部に「オフラインです」というバナーが表示され、保存・削除・復元などの
操作ボタンは自動的に無効化されます。オンラインに戻ると自動的に同期されます。

## フォルダ構成

```
.github/workflows/deploy.yml   GitHubにアップロードすると自動でビルド・公開する設定
src/
  components/   再利用可能なUIコンポーネント(ヘッダー・ナビ・ダイアログ等)
  pages/        画面単位のコンポーネント(ログイン・ホーム・カレンダー等)
  hooks/        カスタムフック(Firestore購読・オンライン状態等)
  contexts/     React Context(認証状態)
  lib/          外部サービス連携(Firebase・予約CRUD・売上集計・バックアップ等)
  lib/firebaseConfig.ts   Firebaseの設定値(GitHub上で直接編集する)
  types/        TypeScript型定義
  utils/        汎用ユーティリティ関数(金額整形・日付計算・カレンダー計算)

firestore.rules   Firestoreセキュリティルール(Firebase Consoleにコピペする)
public/icons/     PWAアプリアイコン(LNモノグラム)
```

## パソコンで動作確認したい場合(任意・上級者向け)

GitHubにアップロードするだけで公開できるため必須ではありませんが、手元でも確認したい
場合は以下の手順で可能です(Node.jsのインストールが必要です)。

```bash
npm install
npm run dev
```

## 既知の制約(無料・サーバーレス構成のため)

- **ゴミ箱の30日後自動削除**: 定期実行サーバーを使わない構成のため、「ゴミ箱画面を
  開いたタイミングで期限切れのデータをまとめて削除する」方式です。30日間誰もゴミ箱を
  開かなかった場合、削除が少し遅れることがあります。
- **パスワード変更**: 「ログイン中の自分自身のパスワード」しか変更できません。
  もう一方のアカウントのパスワードをリセットしたい場合は、Firebase Consoleの
  「Authentication」→「Users」から手動でリセットしてください。
- **オフライン閲覧**: 予約データ、アプリ本体ともにオフラインで閲覧できますが、
  オフライン中の書き込み(保存・削除等)は「閲覧のみ可能」という要件に合わせて
  意図的に無効化しています。
- **Firestoreの複合インデックス**: データが増えて特定の絞り込み検索が必要になった際、
  ブラウザの開発者ツールに「index を作成してください」というリンク付きのメッセージが
  表示されることがあります。表示されたリンクをクリックすると、Firebase Console上で
  ワンクリックでインデックスを作成できます(反映まで数分かかります)。
